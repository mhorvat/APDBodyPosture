# Affective Picture Databases Body Posture Dataset

This repository contains the complete dataset created for the research presented in the scientific paper "**Human Pose Estimation in Affective Picture Databases: An Open Dataset of 2D Skeletal Keypoints**" published at the 68th International Symposium ELMAR-2026, held in Zadar, Croatia, 21-23 September 2026.

Conference website: <a href="https://www.elmar-zadar.org/2026/" target="_new" rel="noopener">https://www.elmar-zadar.org/2026/</a>

The paper can be accessed here: <a href="https://doi.org/10.1109/ELMAR71231.2026.11712195" target="_new" rel="noopener">https://doi.org/10.1109/ELMAR71231.2026.11712195</a>

**The created dataset is available for research and non-commercial use only.**

If you are using the dataset please correctly cite the paper as:

M. Horvat and L. Joja, "Human Pose Estimation in Affective Picture Databases: An Open Dataset of 2D Skeletal Keypoints," in *Proc. 68th Int. Symp. ELMAR*, Zadar, Croatia, Sep. 24, 2026, pp. 265–272, doi: 10.1109/ELMAR71231.2026.11712195.
